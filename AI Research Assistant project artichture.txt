AI Research Assistant
├── Input Layer
│   ├── User Query (Natural Language)
│   └── Context Upload (PDFs, URLs)
│
├── Agent Layer
│   ├── Planner Agent → Breaks query into tasks
│   ├── Retriever Agent → Fetches relevant docs (RAG)
│   ├── Analyst Agent → Summarizes + compares info
│   └── Critic Agent → Validates hallucination
│
├── ML Layer
│   ├── Embeddings Model (e.g., Sentence Transformers)
│   └── Ranking Model (Relevance scoring)
│
├── GenAI Layer
│   └── LLM (GPT / LLaMA) → Final answer synthesis
│
└── Output Layer
    ├── Structured Report
    └── Citations + Confidence Score
